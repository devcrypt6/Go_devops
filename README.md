
# Go_devops
This repo contains go_lang sessions 


## Commit Messages
 - **Format:** Type(scope): subject
 - **Types:** feat, fix, refactor, perf, docs, test, build, ci, chore, deps
 - **Scope:** a folder/package from this repo (e.g., 1_hello_world, 2_packages, 3_variables, Challenge_1)
 - **Subject:** imperative mood, ~50 chars, no period
 - **Body:** explain what changed and why; include impact or metrics
 - **Footer:** `Refs #123`, `Fixes #123`, `BREAKING CHANGE:` if needed

### Examples (tailored to this repo)
 - feat(2_packages): add math utils for float ops
 - fix(1_hello_world): handle empty args in greeting
 - refactor(3_variables): simplify declarations using short form
 - perf(Challenge_3): reduce allocations in parser
 - test(4_constants): add table-driven tests for constants
